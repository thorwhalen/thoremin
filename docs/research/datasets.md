# Datasets thoremin has trained, tuned or measured on

This table lists every clip set and dataset thoremin has used to train, tune, test or measure anything. For each one it gives where the source came from, its licence, what used it, which derived streams exist, where they live, and whether the raw media is kept. The rule behind it is the dev skill [`thoremin-dev-video-data`](../../skills/thoremin-dev-video-data/SKILL.md): every downloaded video keeps all its landmark streams (pose, hands, face) with a `meta.json`, and the video itself may be deleted. **Add a row when you add a source.**

Where things live is stated in repository terms:

- **committed fixture**: under `test/fixtures/`. Only sources whose licence allows redistribution go there, with attribution in the fixture's `meta.json` or `README.md`.
- **app-data dir**: under the app-data root (`THOREMIN_DATA_DIR`, else the platform's user data dir for `thoremin`), at `<kind>/<corpus>/`. Never committed. Each clip has `<id>.meta.json` with the source URL, licence, the source's own description, the labels and where each label came from, the video's sha256 and size, and each stream's extractor and model.
- **regenerable**: rebuilt from code and seeds. Nothing needs to be kept.
